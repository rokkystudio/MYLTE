# MYLTE

MYLTE — Android-приложение для ручного выбора типа сети оператора, просмотра технических данных сотовой сети и отображения данных о сотовых вышках.

Версия: `0.1.5`.

В приложении есть верхняя шапка NeoUI и нижний NeoUI-навигатор с двумя экранами: `Режим сети` и `Карта вышек`.

## Сборка

```powershell
.\gradlew.bat :app:assembleDebug
```
